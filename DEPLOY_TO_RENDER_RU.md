# Публикация QAIRO на Render

## Что подготовлено

`render.yaml` указывает Render запускать `local_server.py` на Python без сторонних пакетов. Команда сборки только проверяет Python-файлы; `pip install` не используется. Сайт будет публичным: любой человек с адресом сможет его открыть. Не вводите в демо реальные персональные данные студентов.

## 1. Загрузить проект на GitHub

1. Войдите в GitHub и создайте пустой репозиторий. Можно выбрать публичный или приватный; приватный репозиторий нужно будет разрешить для Render.
2. На компьютере откройте PowerShell в исходной папке проекта `outputs`, где уже создан локальный Git-коммит. ZIP-копия проекта намеренно не включает скрытую папку `.git`.
3. Скопируйте HTTPS URL репозитория со страницы GitHub и выполните команды, подставив этот URL вместо примера:

```powershell
git remote add origin https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY.git
git push -u origin master
```

Если GitHub попросит войти, завершите вход в официальном окне браузера. Не отправляйте пароль, одноразовый код или токен в чат.

## 2. Создать веб-сервис на Render

1. Войдите в Render и подключите GitHub, если он ещё не подключён.
2. В Render Dashboard выберите **New → Blueprint**.
3. Найдите репозиторий QAIRO и нажмите **Connect**.
4. Выберите ветку `master`. Blueprint находится в корне проекта и называется `render.yaml`.
5. Проверьте, что Render показывает один веб-сервис `qairo-smart-ai-study-assistant` и план **Free**. Если интерфейс показывает платный план или неожиданные ресурсы, не подтверждайте создание и сначала проверьте настройки.
6. Нажмите **Deploy Blueprint**. Render соберёт проект и запустит сервер. Сборка выполняет `python -m py_compile learning_engine.py local_server.py`; дополнительные Python-пакеты не устанавливаются.

Эти шаги соответствуют [официальной инструкции Render по Blueprints](https://render.com/docs/infrastructure-as-code). Сервис настроен на публичный HTTP-трафик: Render требует привязку к `0.0.0.0` и к порту из `PORT`; это уже задано в `render.yaml` и `local_server.py` ([справка о веб-сервисах](https://render.com/docs/web-services)).

## 3. Проверить и отправить ссылку

1. Дождитесь статуса **Live** на странице сервиса.
2. Откройте выданный Render адрес `https://…onrender.com`.
3. Дополнительно проверьте `https://ВАШ-АДРЕС.onrender.com/api/health`: ответ должен содержать `"status":"ok"`.
4. Откройте викторину, ответьте на вопрос, проверьте вкладки Байеса и ML. Затем отправьте основной HTTPS-адрес друзьям.

При первом открытии после простоя бесплатный сервис может запускаться около минуты. Бесплатные веб-сервисы Render останавливаются после 15 минут без запросов. Перезапуск очищает сессию, потому что она хранится только в памяти. Изучите [ограничения Free плана](https://render.com/docs/free); там также описаны квоты и возможное приостановление сервиса при превышении бесплатного объёма.

## Если развёртывание завершилось ошибкой

- Откройте страницу сервиса → **Logs** и найдите первую ошибку запуска или сборки.
- Проверьте, что в репозитории есть `render.yaml`, `local_server.py`, `learning_engine.py`, `templates/` и `static/`.
- Оставьте команды сборки и запуска из Blueprint. Не заменяйте сборку на `pip install -r requirements.txt`: он относится к старому необязательному Flask-варианту, а опубликованная версия работает на стандартной библиотеке.
- Если GitHub или Render просит добавить платёжные данные либо выбрать платный план, остановитесь и проверьте экран тарифа; для учебной демонстрации достаточно Free плана, пока соблюдаются его лимиты.
