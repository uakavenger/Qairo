# QAIRO — Ақылды оқу көмекшісі

Қазақ тіліндегі интерактивті оқу сайты. Жергілікті нұсқасы Python стандартты кітапханасымен жұмыс істейді: аккаунт, API кілті, интернет, Flask, scikit-learn немесе пакет орнату қажет емес. HTML, CSS, JavaScript және алгоритмдер жоба ішінде сақталған.

## Іске қосу

Python 3.10+ орнатылған Windows компьютерде `start_windows.bat` файлын екі рет басыңыз. Басқа жүйелерде `python3 launch.py` (Windows-та `py -3 launch.py`) командасын орындаңыз. Іске қосқыш жергілікті серверді бастап, браузерде сайтты ашады. Сервер тоқтамай тұрғанша сайт `http://127.0.0.1:5000` мекенжайында жұмыс істейді; тоқтату үшін терминалда `Ctrl+C` басыңыз.

Қолмен іске қосу: `python local_server.py`, содан кейін браузерде жоғарыдағы жергілікті мекенжайды ашыңыз. Сыртқы желіге қосылмайды.

## Үш бөлек алгоритм

- **5-апта — Q-learning:** жауап сыйақысы бар, үш әрекетті табличалық Q-learning; ε-greedy саясат келесі тапсырманың күрделілігін бейімдейді.
- **6-апта — Байес қорытындысы:** априорлық баға мен дұрыс/қате жауаптардың likelihood мәндерін біріктіріп, меңгеру posterior ықтималдығын есептейді.
- **8-апта — классикалық ML жіктеуі:** синтетикалық деректе оқытылатын, осы репозиторийдегі multinomial Logistic Regression. Белгілер стандартталады, softmax ықтималдықтары есептеледі және 75/25 бөліктегі accuracy, macro precision, recall, F1 көрсетіледі.

Бұл үш есеп браузерде безендірілген мәтін ғана емес: API оларды Python-да нақты орындайды. Жіктеу дерегі демонстрациялық, шынайы оқушылар туралы қорытындыға жарамайды.

## Тексеру

Python 3.10+ болса, пакет орнатпай:

```text
py -3 -m unittest -v
```

macOS/Linux-та `python3 -m unittest -v` қолданыңыз. Тесттер статикалық файлдарды, API диспетчерін, сессия мен сұрақ/жауап ағынын, валидацияны, алгоритмдерді және Render конфигурациясын тексереді. Тест жиыны жергілікті желі портына байланыспайды.

Жергілікті сервер мен негізгі API бағыттарына нақты HTTP smoke-тест алдыңғы тексеруде орындалды. Қазіргі нұсқада **12 офлайн тест** алгоритмдерді, API диспетчерін, сайт файлдарын және Render үшін `HOST`/`PORT` баптауларын тексереді. Браузерде сайт ашылып, қазақша quiz интеракциясы тексерілді. Презентация 7 слайдпен render жасалып визуалды қаралды.

## Құрылым

```text
outputs/

├── learning_engine.py         # Q-learning, Bayes және логистикалық регрессия

├── static/js/app.js
├── test_app.py
├── README.md
```

Оқу сессиясы тек жадта сақталып, сервер тоқтағанда өшеді. Тіркелу, дерекқор, cookie немесе сыртқы қызмет жоқ.

## GitHub және Render арқылы жариялау

Жобаға `render.yaml` қосылды. Ол Render-ді стандартты кітапхана серверімен іске қосады: құрастыру кезінде пакеттер орнатылмайды, ал Render ұсынған `PORT` және `0.0.0.0` хосты қолданылады. Render веб-қызметі сұрауларды қабылдау үшін `0.0.0.0` адресі мен `PORT` айнымалысына байланысуы керек екені [ресми нұсқаулықта](https://render.com/docs/web-services) жазылған. Render Dashboard-та `New > Blueprint` таңдаңыз, Git репозиторийін байланыстырыңыз да, `Deploy Blueprint` батырмасын басыңыз. [Blueprint нұсқаулығын](https://render.com/docs/infrastructure-as-code) қараңыз.

1. GitHub-та бос repository ашыңыз. README, `.gitignore` немесе лицензия файлын GitHub-та алдын ала қоспаңыз.
2. Осы қалтадан PowerShell ашып, GitHub бетінде көрсетілген URL-ді қолданыңыз:

```text
git remote add origin https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY.git
git push -u origin master
```

`YOUR-ACCOUNT` және `YOUR-REPOSITORY` орнына өз мәндеріңізді қойыңыз. Жергілікті commit дайын. GitHub немесе Render паролін чатқа жібермеңіз. Толық нұсқа (орысша): `DEPLOY_TO_RENDER_RU.md`.

Render-дегі Free веб-қызмет 15 минут сұраныс болмаса ұйқы режиміне өтеді; келесі ашылуы шамамен бір минут алуы мүмкін. Қайта қосылу сессияны жадтан тазартады. [Free жоспарының шектеулерін](https://render.com/docs/free) алдын ала қараңыз. Сайттың оқу сессиялары тұрақты сақталмайды.

Ескерту: `server.py` және `requirements.txt` Flask-тың балама жергілікті іске қосылуына ғана қалдырылған. Render Blueprint ол файлдарды қолданбайды және пакеттерді орнатпайды.

Пайдаланушы атаған екі түпнұсқа DOCX бұл жұмыс ортасындағы қолжетімді файлдардан табылмады; сондықтан нақты rubric, тапсыру пішімі және балл бөлінісін толық сәйкестендірдік деп айтуға болмайды. Тапсырар алдында студент аты-жөнін, топ мүшелерін және оқытушының түпнұсқа талаптарын тексеріп, толтырыңыз.
